# Setup Sprint invitation

Invites employees to a Setup Sprint where small groups test and document each project's dev environment setup before applications open.

**When:** Send at T-15w to T-14w. Hold the sprint at T-13w to T-11w.
**Sent by / owner:** Program organizer (optionally co-hosted with an employee resource group)
**Audience:** Employees interested in open source, especially anyone with experience in the participating projects

## How to use

- Send the sprint survey with sign-up: in person or remote, which laptop and operating system, and dietary needs.
- Have draft setup guides ready (see 06-dev-environment-setup-guide-outline.md) and assign each group a project and an environment.
- Cover every environment participants will use, including any company-managed laptops and a cloud dev environment fallback.
- Ask groups to record fixes directly in the guide (comments or suggested edits), then close all open comments before T0.
- Use the sprint as recruitment: attendees are strong applicants and future mentors.
